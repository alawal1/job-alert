# Preferences

Everything the agent needs to know about what you are looking for. This is an example with fictional places. Replace it with your own.

## Places, in order of preference

- **Exampleland:** Port Sample, then Northbridge, then other cities in Exampleland, or remote.
- **Samplestan:** Westfield or Lakeview only. Other cities in Samplestan only count if the job is remote.

Remote counts in: Exampleland, Samplestan.

## Work modes

On-site, hybrid and remote all count.

## Levels

entry-level, graduate, trainee, junior, internship, traineeship

## Fields that usually fit

data analytics, project coordination, communication, and similar roles that match the profile.

## Languages (with levels)

Use one of: native, fluent, conversational, basic.

- Language A: native
- Language B: fluent
- Language C: conversational

## Dealbreakers

- **Maximum years of experience:** 2. A posting that asks for 2 or more years is dropped, even if the title says junior. Some experience under the limit (for example 1 year) is kept with low confidence.
- **Languages:** a posting that requires a language at a level you don't have is dropped. A language named only as a plus is kept.
