# Companies and where to search them

One block per company. For each country there's a **search link that worked**, **how to read it** (fetch = a simple page fetch is enough; browser = the page needs the built-in browser because jobs load with JavaScript), and **quirks** learned on earlier runs.

Last checked: YYYY-MM-DD (run N). If a link stops working, fix it here, not in the chat.

This is an example with fictional companies. Replace everything below with your own list.

## Northwind Analytics
- **Exampleland:** https://careers.example.com/northwind?query=junior&location=Exampleland
  - also run: `query=intern`, `query=graduate`
- **Samplestan:** https://careers.example.com/northwind?query=junior&location=Samplestan
- **How:** browser. A search word is required; an empty search shows nothing useful.
- **Quirks:** most roles tagged "Entry Level" are engineering. Thesis placements show up under entry level but are meant for current students.

## Contoso Labs
- **All locations:** https://careers.example.com/contoso
- **How:** fetch. One page lists every role with its location.
- **Quirks:** titles carry no level, so the level filter doesn't work. Open any non-senior role in a fitting field and read the requirements. Entry roles say "recent graduate" in the text.
